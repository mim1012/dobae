# 우리도배

사용자 제공 시안을 바탕으로 하늘색·화이트 색상과 가벼운 글꼴을 적용한 반응형 사이트입니다. 모든 페이지가 화면 폭에 맞춰 확장되며, 우리도배 공식 블로그의 실제 현장 7건과 사진 80장을 사용합니다. 페이지별 구성과 실제 정보의 출처는 [REFERENCE-NOTES.md](./REFERENCE-NOTES.md)에 정리했습니다.

## 실행

```sh
npm install
npm run dev
```

개발 주소: http://127.0.0.1:5173

```sh
npm test
npm run build
npm run preview
```

`dev`와 `preview` 모두 상담 API를 포함합니다. `dist`만 정적 호스팅할 때는 별도의 상담 API가 필요합니다.

## 페이지

- `/`: 첨부 시안에 맞춘 메인
- `/about`: 회사소개, 상담 방식, 연락처
- `/portfolio`: 평형·벽지·지역 검색, 더 보기
- `/portfolio/:slug`: 현장별 실제 시공 범위, 상세 탭, 단계별 사진 갤러리·확대 보기, 원문, 상담 연결
- `/stores`: 실제 매장 주소·전화·시간, 주소 복사, 지도 연결
- `/guide`: 우리도배 블로그 원문, 주제별 안내 글, FAQ
- `/guide/hapji-silk`, `/guide/process`, `/guide/defect`, `/guide/estimate`: 개별 안내 글
- `/consult`: 상담 양식
- `/finder`: 공간·분위기·질감 선택과 상담 내용 전달
- `/privacy`: 현재 개발 환경에서의 정보 처리 안내

모든 페이지는 별도 URL로 직접 접속·새로고침할 수 있습니다. 호스팅 시 SPA fallback을 `index.html`로 설정해야 합니다.

## 동작과 효과

스크롤에 맞춘 제목·사진의 등장과 카드 순차 등장, 스크롤 진행 표시, 카드·버튼 호버, 필터 전환, 모바일 메뉴·모달, 사진 확대·이전/다음 이동, FAQ, 맨 위로 이동, 벽지 선택 단계 전환을 구현했습니다. 메인 시공사례는 자동으로 다음 카드로 이동하고, 카드별 썸네일로 대표 사진을 선택할 수 있습니다. 자동 넘김은 마우스·키보드·터치 조작 중 멈추며, 모션 감소 설정과 키보드 포커스를 지원합니다. 사진 확대 창은 좌우 방향키와 Escape로 조작할 수 있습니다.

상담은 필수 입력, 전화번호, 날짜, 개인정보 동의, 첨부 형식·용량을 검사합니다. 최대 5장, 장당 10MB, 총 25MB입니다. 접수 결과에 접수번호를 표시하고 입력 내용을 텍스트로 내려받을 수 있습니다.

## 상담 저장과 운영 범위

`POST /api/consultations`는 `.data/consultations/<접수번호>/`에 요청 JSON과 첨부 파일을 저장합니다. 이 폴더는 Git에서 제외되며 Vite의 파일 접근 차단 대상입니다. 서버는 입력 검증, 동일 출처 검사, 요청 용량 제한과 호출 횟수 제한을 적용합니다. `GET /api/health`로 실행 여부를 확인할 수 있습니다.

현재는 **로컬 테스트 접수**입니다. 외부 메시지나 실제 시공 예약을 보내지 않으며 화면에 이 상태를 안내합니다. 정식 운영 전에는 운영 서버·접수 관리/알림·실제 보유기간과 개인정보 처리방침을 연결해야 합니다. 테스트 기록은 검증 후 관리자가 삭제합니다.

## 검증

- TypeScript 검사 및 배포 빌드
- Node 테스트: 필수 입력·동의·날짜, 첨부 제한, HTTP 접수·파일 저장·출처 거부
- 브라우저: 5개 메뉴 경로, 평형·검색·더 보기, 사례 상세·상담 연결, 가이드 필터·상세, 3단계 벽지 선택, 주소 복사, 상담 오류·테스트 저장·다운로드
- 390px 모바일 경로별 가로 넘침 및 메뉴 확인

React · TypeScript · Vite · Tailwind CSS · Motion · Radix Dialog · Lucide를 사용합니다. Pretendard Variable 글꼴은 `public/fonts`에서 직접 제공하며, OFL 라이선스를 함께 포함합니다.
